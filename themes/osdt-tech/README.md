# OSDT Tech

OSDT Tech 是一个面向 OSDT / HelloGCC 社区博客的 Hugo 主题，提供深色科技风首页、文章卡片列表和长文阅读页样式。

## 使用方式

1. 在站点配置中启用 `theme = "osdt-tech"`。
2. 提供 `params.heroTitle`、`params.heroSubtitle` 和 `params.repoURL`。
3. 将博客文章放在 `posts` section 下，页面内容放在独立 section 中。

## 主题特性

- 深色科技感首页
- 博客卡片流式列表
- 中文友好的长文阅读样式
- 可直接配合 Hugo Pipes 构建 CSS
